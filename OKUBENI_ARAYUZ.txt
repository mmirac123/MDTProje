  1. ISIM KONVANSIYONU  -  KOD YAZMADAN ONCE HERKES OKUSUN
--------------------------------------------------------------------------------
  Sinyal isimleri Turkce, modul isimleri ve teknik terimler Ingilizce.
  Zaten yazilmis timebase/debouncer ile uyumlu:

    vurus_1ms      1 ms izin pulsu (timebase -> herkes)
    disp_sel       7-segment tarama secicisi
    btn_ham        ham buton girisi

  BIR ISMI DEGISTIRIRSENIZ GRUBA HABER VERIN. Dort kisi paralel yaziyor;
  bir port isminin sessizce degismesi entegrasyon gununu yakar.

--------------------------------------------------------------------------------
  3. SABITLER  -  hepsi tek yerden gelsin, dagitmayin
--------------------------------------------------------------------------------
  MS_DIV        = 100_000   (sentez)  /  10 (simulasyon)
  CLKS_PER_BIT  = 10417     (9600 baud @ 100 MHz)
  STABLE_MS     = 10        (debounce esigi)
  Blackout penceresi = 5000 ms
  SEQ adim suresi    = 400 ms
  Kolay mod = 2000..5000 ms   |   Zor mod = 500..5000 ms
  Puan: 1.=4  2.=3  3.=2  4.=1  |  false start / timeout = 0
  LED sayisi = puan sayisi (ayri hesap yapmayin)

--------------------------------------------------------------------------------
  4. IS BOLUMU ONERISI
--------------------------------------------------------------------------------
  A (entegrator) : top, XDC, seg7_driver, led_ctrl, kart ustu debug
  B              : game_fsm  (TEK BASINA - kimse karismasin)
  C              : lfsr16, delay_gen, reaction_capture, scoring, score_accum
  D              : uart_tx, bin2bcd, uart_reporter

  Katman 0 (timebase, debouncer) BITTI - hepsi bunlarin ustune oturuyor.

--------------------------------------------------------------------------------
  5. YAZMA SIRASI
--------------------------------------------------------------------------------
  1) lfsr16 + delay_gen        (kolay, bagimsiz)
  2) seg7_driver               (ekranda "1234" gorun - ilk gorsel kilometre tasi)
  3) game_fsm iskeleti         (BTNC ile animasyon + blackout calissin)
  4) reaction_capture + scoring + led_ctrl   <-- burada oyun OYNANABILIR olur
  5) score_accum, false start, timeout, eleme modu, erken bitis
  6) uart_tx (once tek 'A' karakteri!) -> bin2bcd -> uart_reporter
  7) top_tb ile tam sistem simulasyonu, sonra bitstream
